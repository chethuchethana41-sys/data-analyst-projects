# 📊 Excel Dashboard Project – Data Analysis & Visualization

> **Week 1 Internship Project at Aivarient**  
> An end-to-end Excel dashboard project demonstrating data cleaning, transformation, KPI creation, and business-focused data visualization.

---

## 🚀 Project Overview

This project was completed as part of my **Week 1 internship at Aivarient**.  
The goal was to transform raw data into **meaningful, decision-ready insights** using **Microsoft Excel** and **Power Query**.

The project follows a complete analytics workflow — from data preparation to dashboard storytelling — similar to real-world business reporting.

---

## 🎯 Objectives
- Clean and standardize raw datasets  
- Merge multiple queries and append files efficiently  
- Create KPI metrics for performance tracking  
- Design an interactive and easy-to-read dashboard  
- Ensure data accuracy, consistency, and usability  

---

## 🧠 Key Work Done
- Data cleaning and preprocessing  
- Query merging and appending using **Power Query**  
- KPI calculation and validation  
- Interactive charts and visual summaries  
- Dashboard layout optimized for business users  

---

## 📊 Dashboard Features
✔ KPI Cards for high-level insights  
✔ Interactive charts for trend analysis  
✔ Clean and professional dashboard layout  
✔ Automated data transformation using queries  
✔ Easy refresh with updated data
